截至 2026-09-04，项目主线已经完成用户管理、学籍管理、选课、图书馆、校园商店五个业务模块的服务端分发、权限校验、Access 持久化骨架和 Swing 客户端入口。最新主线已合入 PR40，明确学生/教师档案与账号身份分离，教师授课范围由服务器根据登录 token、教师档案、教学班和有效选课记录判定。

## 三、本地 PR 主要改动

1. 重做主界面工作台：新增账号状态、可用模块数量、数据状态和快捷操作区。
2. 优化角色导航：侧栏改为更稳定的纵向布局，选中项增加可见状态标识。
3. 统一业务页面外观：用户、学籍、选课、图书馆、商店页面使用一致的标题区、表格区、按钮和状态提示。
4. 改善小窗口体验：新增自适应卡片行、可滚动页面容器和自动换行工具栏，降低窗口缩放时的内容截断风险。
5. 新增本地功能助手：根据当前角色可见模块，支持选课、学籍、图书馆、商店等关键词问答和快捷跳转，不依赖外部模型 API。
6. 补充客户端回归测试：覆盖工作台布局、快捷操作、滚动行为、卡片布局、导航主题和用户管理页面状态。

## 四、数据库与部署策略

当前验收数据库采用最新 `database/schema.sql` 和 `database/seed.sql` 重建，不再承诺把历史 `.accdb` 逐条迁移到最新结构。旧库如需保留数据，应先人工备份，再按新 schema 重建并导入必要演示数据。

这样可以避免多个并行 PR 的历史迁移脚本互相影响，也能保证教师档案、钱包、图书馆和学籍字段在验收环境中一次性对齐。
