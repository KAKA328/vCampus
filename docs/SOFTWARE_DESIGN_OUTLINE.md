# 软件设计说明书填写提纲

本文件对应课程提供的《软件设计说明书DEMO》，用于分工后逐项补全，最终应提交 Word 版本。

1. 引言：编写目的、背景、概述、参考资料、项目成员。
2. 系统分析：可行性分析、需求分析、开发环境和工具。
3. 系统结构：系统框图、客户端/服务器端分层、模块依赖图。
4. 用户管理模块：注册、注销、登录、登出、授权的流程、界面、实体和接口。
5. 学生学籍管理模块：业务流程、实体类、接口和数据库表。
6. 选课系统模块：课程查询、选课、退选、成绩相关流程和约束。
7. 图书馆模块：图书查询、借阅、归还和库存约束。
8. 商店模块：商品查询、购买、库存和交易约束。
9. 公共模块：`Message` 协议、序列化对象、状态码和异常处理。
10. 网络与多线程：Socket、对象流、线程管理、断线处理、多客户端处理。
11. 数据库设计：E-R 图、表结构、字段类型、主键/外键/唯一/非空约束、测试数据。
12. 界面设计原型：登录、主界面和五个业务模块的关键页面。
13. 测试与验收：测试用例、权限矩阵、容错场景、部署启动步骤。

说明书中的类名、接口名、消息类型和数据库字段必须与代码及脚本保持一致。
