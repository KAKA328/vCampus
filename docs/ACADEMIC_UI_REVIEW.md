# 学籍前端对照与完善记录

日期：2026-09-06。范围：本地当前代码的 Swing 客户端。沿用 VCampusTheme 的蓝白配色、微软雅黑、统一按钮及表格样式，不引入网页框架。

## 对照其他模块

| 模块 | 当前页面组织 | 学籍侧借鉴 |
|---|---|---|
| 商店 | 商品、购物车、订单、钱包分区；余额提示独立；部分切换页签自动加载 | 同类操作集中成明确分区，关键数值突出显示 |
| 图书馆 | 目录/借阅记录分开；查询栏、结果表、操作栏层次清楚；表格支持排序 | 查询与办理分区，表格使用统一样式、排序和结果状态 |
| 选课管理 | 课程目录/教学班页签；表单与表格结合；输入较密集、支持折行 | 保留适合桌面的表单操作，但减少同屏堆叠并允许整页滚动 |

对照基于源代码与离屏页面渲染；其他模块使用未加载数据的初始页面，不代表本轮对其全部真实业务做过人工验收。截图表头未显示等离屏差异不直接认定为线上缺陷。

## 本轮学籍改动

- 学生当前学分用四张卡片显示累计学分、已通过课程、当前待重修、历史重修；另列学号及统计口径。窗口窄时卡片自动换行，加载及失败时清空旧指标。
- 教师页增加姓名身份区与在职状态标签；刷新按钮置于标题栏首屏，全部字段仍只读。
- 教务操作分为“人员查询”和“学分审查与毕业”，办理学号始终可见。审查区标明保存审查、核查其他条件、确认毕业的步骤。
- 教务表格新增本地关键词筛选、表头排序和结果数量；排序/筛选后按视图行转换到数据行确定目标学生，避免选错毕业对象。数字列按数值排序。
- 教务操作区按当前页签内容决定高度；整页可以纵向滚动，多列表格保持横向滚动。
- 学生档案在宽度不足740px时改为结果在上、编辑区在下，较宽时恢复左右布局。
- 模块标题、页签、输入框、滚动条和只读说明统一。未改变服务端业务、角色权限、学分口径或数据库。
