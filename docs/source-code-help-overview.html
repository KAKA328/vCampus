vCampus 虚拟校园系统源代码帮助文档

本电子文档由 JDK 的 javadoc 程序生成，覆盖各模块 src/main/java 下的生产源码，并显示内部实现成员，供课程验收、代码阅读和维护使用。

覆盖模块

  • common：共享 DTO、协议、权限与公共工具。
  • user-management：账号、角色、会话、审计与档案绑定。
  • student-management：学生和教师档案、学籍维护。
  • course-selection：课程、教学班、选退课、培养方案与成绩。
  • library：馆藏、借阅、归还、遗失赔偿。
  • store：商品、订单、库存与校园钱包。
  • server：Socket 服务、请求分发和持久化适配。
  • client：Swing 客户端、页面、传输与本地交互。

重新生成

在仓库根目录执行：

powershell -ExecutionPolicy Bypass -File .\scripts\Build-SourceCodeHelp.ps1 -Overwrite

该脚本会先编译项目并解析课程模块的第三方依赖，再调用 JavaDoc 生成到 docs/source-code-help。-Overwrite 只会清理该生成目录中的旧文档。

阅读说明

从 index.html 打开。页面顶部可按模块包名导航，类和接口页面可查看字段、构造器、方法及其 JavaDoc 注释。
